# Programa para Windows

Coloque aqui o programa do Preparatório (o executável e, se tiver, a pasta do projeto).
É daqui que as 2.000+ questões vão para o site (`docs/dados/banco.json`).

## Como enviar pelo navegador

1. Nesta pasta do GitHub, clique em **Add file** → **Upload files**.
2. Arraste os arquivos e clique em **Commit changes**.

O GitHub aceita até **25 MB por arquivo** pelo navegador. Se o `.exe` for maior:

- **Melhor opção:** envie a pasta do projeto (o código que o Claude Code criou), sem as pastas
  `node_modules`, `dist` e `out`. As questões costumam estar num arquivo `.json` ou `.js` lá dentro.
- **Ou:** na página principal do repositório, **Releases** → **Create a new release** → anexe o `.exe`
  (aceita arquivos grandes) → **Publish release**.
